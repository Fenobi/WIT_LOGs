# tools/ — 上位机与脚本工具

> 与记录仪配套的电脑端工具，Python 3 + pyserial。

## 计划脚本（M2.9 实现）

| 脚本 | 功能 |
|------|------|
| `witmon.py` | 串口终端 + 配置命令交互（采样率、通道使能、时间下发、状态查询） |
| `export.py` | 数据导出与转换（二进制 → CSV），统计丢条检查 |

## 使用约定

- 每个脚本支持 `--help`，公共串口参数统一：`-p COMx -b 115200`；
- 依赖清单写入 `requirements.txt`；
- 脚本输出统一追加到 `logs/`（git 忽略）。
