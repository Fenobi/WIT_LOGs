## 固件目录结构预告（M2.1 搭建时定稿）

```text
firmware/
├── project/        工程文件（EIDE/Keil/CubeMX .ioc）
├── Core/           CubeMX 生成的启动、时钟、外设初始化
├── drivers/        传感器驱动、显示驱动（统一 sensor_if 接口）
├── middleware/     FatFs、环形缓冲、命令解析、配置管理
├── app/            记录控制状态机、主应用逻辑
└── build/          构建输出（git 忽略）
```
