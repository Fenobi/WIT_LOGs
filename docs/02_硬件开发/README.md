## 本项目硬件设计要点（与通用板不同处）

- ⚠️ CAN 收发器必须是 **FD 型**（TJA1044GT/3 或 MCP2562FD 级别），经典型号（TJA1050/MCP2551/SN65HVD230）不可用；
- CAN 接口每路：共模电感 + TVS（PESD1CAN 级）+ 板载 120Ω 终端电阻可投切（FR-14）；
- 电源输入 9~24V DC（车载/工业）与 USB 5V 双路，防反接；
- 隔离版（隔离收发器/DC-DC）v1 不做，PCB 布局预留空间；
- SDMMC 4-bit 座布线遵循等长/短走线原则；
- 第 3 路 FDCAN 是否引出 → 开发计划 M3.1 决策（Q8）。
