> ⚠️ **校验约定**：本表按 STM32H7 系列复用(AF)惯例初排。**CubeMX 生成的 AF 表是权威**——M2.1 工程搭建时逐脚核对，任何冲突在本表修订后冻结。设计原则：避开 PA11/12（USB）、PA13/14（SWD）、PA9/10（调试串口+USB VBUS 区域）。

## 2. 板载资源占用（WeAct H723VGT6，以实物原理图为准）

| 板载资源 | 引脚（待实物核对） | 本项目用途 |
|----------|---------------------|-----------|
| LED ×2 | PB0 / PB1（待核对） | 电源指示 / 状态 LED（开发板阶段） |
| KEY | PC13（待核对） | KEY_REC（开发板阶段） |
| USB-C | PA11/PA12 | CDC 通信 |
| SD 卡座 | **核板大概率无 SD 座** → 开发板阶段用 SPI-SD 模块过渡或 SDMMC 转接板 | storage_if 适配层已隔离 |

## 3. 冲突检查记录

| 检查项 | 结果 |
|--------|------|
| PA11/12 (USB) 未被其他功能占用 | ✅（CAN1 特意避开 PA11/12，选 PB8/9） |
| PB8/9/12/13 无复用冲突 | ☐ M2.1 CubeMX 核对 |
| PC8~12+PD2 (SDMMC) 无冲突 | ☐ M2.1（PD2 是 LQFP100 唯一 PD 脚，仅 SDMMC CMD 用，无冲突） |
| UART4 PA0/PA1 与 USART2 PA2/PA3 相邻但不冲突 | ✅ |
| DMA 通道冲突（SDMMC DMA vs USART DMA） | ☐ M2.1（SDMMC1 用 MDMA/DMA 通道按 CubeMX 分配） |
| 第 3 路 FDCAN3 是否引出 | ⬜ M3.1 决策（Q8）——候选 PA8/PD12 区域，LQFP100 引脚有限，倾向**不引出**（2 路已满足 v1） |

## 4. 开发板阶段过渡方案

- SD：SPI-SD 模块（SPI1: PA5 SCK / PA6 MISO / PA7 MOSI + CS PB5）→ storage_if 适配层切换后端；**测速仅参考，权威测速等 SDMMC**；
- RTC：无 LSE 时走 LSI + USB SET_TIME 周期同步（见 §5）；
- CAN：两个 FD 收发器模块接 PB8/9、PB12/13，**共地**，终端电阻各 120Ω（模块自带跳线）。

## 5. LSE 缺失的影响评估（开发板）

| 影响项 | 评估 |
|--------|------|
| µs 级帧间时间戳 | **无影响**（TIM2 由 HSE 衍生时钟驱动，与 LSE 无关） |
| 绝对时间精度 | LSI 漂移 ~±1-2%，远超 2s/天指标 → 用 USB SET_TIME 每 10min 同步补偿，**测试验收中绝对精度项仅在自制板执行** |
| 掉电走时 | 开发板 VBAT 无电池 → 断电丢 RTC；续记逻辑已按"文件系统扫描为权威"设计，不受影响 |
