## 3. 风险登记册

| # | 风险 | 概率 | 影响 | 缓解措施 |
|---|------|------|------|----------|
| R1 | USB FS 吞吐不足以承载满载实时流 | 高 | 中 | 架构即按"SD 记录为准、USB 流为辅"设计；流控降级（过滤/抽样）；HS+ULPI 仅作 v2 选项（Q4） |
| R2 | H7 时钟树复杂（550MHz M7 + FDCAN kernel clock 分频）配置错误 | 中 | 高 | CubeMX 生成 + ST 官方 FDCAN 例程起步；时钟配置单元测试 |
| R3 | FDCAN 共享 Message RAM 三实例分配不当导致溢出 | 中 | 高 | M1.6 定量分配；运行时溢出计数与日志 |
| R4 | 劣质/低速 SD 卡导致满载写入瓶颈或寿命问题 | 中 | 高 | 高耐久卡；写入耗时统计与告警；适配层可换卡实测 |
| R5 | 掉电保护策略漏洞 | 中 | 高 | 批量块写+定时 f_sync；M5 专项 ≥10 次；文件头双备份 |
| R6 | H7 克隆板/芯片异常 | 低 | 中 | WeAct 口碑较好；到手先跑时钟/外设自检程序 |
| R7 | 需求蔓延（设备端分析、OLED、隔离等） | 高 | 中 | 全部进 backlog 排 v1.x；v1.0 冻结为当前范围 |
| R8 | RT-Thread 在 H723 上的 bsp/SDMMC 驱动兼容性与性能不确定 | 中 | 中 | M2.3 优先实测 DFS/驱动测速；保留裸 HAL + FatFs 回退路径（存储适配层已隔离） |

## 4. 变更管理

- 需求变更：改需求规格说明书 + 修订记录，评估对设计与计划影响；
- M1 冻结后：引脚/数据格式/协议变更须记录原因与影响面；
- 每次会话结束：更新 readme 状态表与本文档勾选。
