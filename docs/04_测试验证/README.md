## 核心测试项（对应需求验收标准）

1. 功能测试：开始/停止、LED 状态、配置修改与持久化
2. 数据完整性：72 h 连续运行无死机、不丢条
3. 掉电保护：记录中拔电 ≥10 次，文件系统无损坏
4. 精度：RTC 走时偏差 ≤2 s/天；温湿度与参考仪器对拍
5. 边界：卡满、分卷、无卡、传感器拔出等异常场景
